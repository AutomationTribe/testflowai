The approved **Projects — List** (`b2b302b729534983880869b8e214b6af`) and **Projects — Empty State**
(`585484247e734477825bf374a61b60ec`) have screenshot links that need a Google login, so their images
cannot be fetched without a signed-in browser. The two lowercase-titled sibling screens above are
near-identical (judged by eye in a logged-in browser, not byte-verified), download without a login, and
are what the screens were actually built and design-checked against (`docs/design/handoffs/projects.md`).
If the approved originals are ever exported, replace these two files with them and delete this caveat.

The designs contain sample content (organisation, people, project names, an environment tag, a "Sprint"
workspace label, repository/schema telemetry, feature cards). None of it is real and none is implemented —
see `docs/design/handoffs/projects.md` for what is deliberately omitted.
